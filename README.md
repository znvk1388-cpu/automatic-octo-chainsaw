# 日拱一卒 · v64

本地优先的习惯打卡应用。支持习惯排程、计数和时长、最低剂量、日记、回顾、番茄钟、待办及备份。应用可作为静态站点部署，或用附带的 Node 服务启动。

## 本次更新

- 戒断型习惯新增「先撑 90 秒」：4-4-4 呼吸引导，挺过去只记次数、不改完成状态。
- 破戒后可选记下触发点（压力 / 无聊 / 情绪 / 社交场合 / 熬夜 / 身体不适 / 其他），
  攒几次后能看到最常触发什么；撤销破戒时原因一并清掉。
- 通知点击打开对应记录入口，不自动打卡；支持日记/回顾跳转、稍后提醒与编辑保护。
- 云连接状态区分登录、待同步、完成与暂停；离线缓存更新到 64.15。

完整说明见 [更新说明-v64.md](更新说明-v64.md)。

## 本地运行和检查

需要 Node.js 22 或更新版本，无需安装第三方依赖：

```sh
npm start
npm test
npm run check
```

启动后打开 http://localhost:3000 。可通过 PORT 环境变量调整端口。测试使用隔离的虚构记录和接口，不会读取或修改线上个人数据。

## 反向代理部署

Node 服务默认用连接的真实来源进行限流，忽略客户端自行填写的 `X-Forwarded-For`。
如果部署在反向代理后，先确认代理会覆盖或追加真实来源，再通过 `TRUSTED_PROXIES` 指定实际可信代理的 IP 或 CIDR，逗号分隔。未配置时，经过同一代理的请求会按该代理来源共同计数。

例如代理仅在本机运行时，可以配置 `TRUSTED_PROXIES=127.0.0.1,::1`；远程托管需按平台确认的实际代理范围配置，不能照抄本机示例，也不要信任所有地址。
实现使用 [Node 内置 net.BlockList](https://nodejs.org/docs/latest-v22.x/api/net.html#class-netblocklist)，不增加依赖。支持多层可信代理，从连接来源向转发链回溯到首个非可信地址。

## 静态托管

将仓库根目录作为静态站点根目录即可。index.html、src、assets、vendor、manifest.webmanifest 和 sw.js 必须一起发布；子目录部署保持相对路径。更新后由应用提示用户刷新，避免静默中断正在编辑的内容。

本地打卡和备份可以离线使用。云同步、短信或微信登录、房间等功能依赖原 WorkBuddy 云后端；静态托管本身不会创建这些后端服务。微信登录还需在后端允许实际站点回调地址。

## 数据与兼容

- 未登录时记录保存在当前浏览器，换设备或清理网站数据前请导出备份。
- v63 为后续规则变更保存生效历史；对于升级前没有保存过的目标和排程，无法推断用户当年实际设置过什么。升级采用已有记录和可用元数据保留事实，不编造历史目标。
- 本次不自动清空、上传或替换现有个人记录。

## 隐私与联网

- **天气默认不联网**：写日记不会自动请求天气。需要时在「我的 → 设置与提醒 → 自动记录天气」手动开启，或每次点日记页的「＋ 加天气」。开启后进入日记会请求 `wttr.in`（对方可见你的 IP）；该请求失败且浏览器允许定位时，再用坐标换取 `api.open-meteo.com` 的天气。
- **搭子令牌不进 URL**：读写搭子进度一律用 `POST /api/read`，令牌放在请求体。`GET /api/state` 仅为旧版 PWA 保留，可在旧缓存淘汰后删除。
- **不引入第三方统计**：服务端用 `Content-Security-Policy: script-src 'self' 'unsafe-inline'` 挡住托管平台注入的统计脚本。
- **房间数据最小化**：搭子/房间只存昵称、习惯名、当天是否完成与连续天数，不存习惯数值、备注、照片和心情；房间数据 90 天无更新自动清理。
- 云同步、WebDAV、Webhook 推送均为可选，未开启时数据不出本机。云同步默认把整份状态明文上传到你的云后端；需要「服务端也读不到」时，在「连接 → 云空间 → 云端备份加密」开启，开启后会立即尝试把当前云副本转为 PBKDF2+AES-GCM 密文；请看到转换完成提示后再清理原设备。转换失败会明确提示未完成，本机加密策略会保留以便重试，密码只存本机浏览器。

## 已知限制

以下不是"待修 bug"，而是当前形态下的边界，写清楚便于判断能不能拿来用：

1. **云端备份加密已支持但有两点边界**：① 照片、语音、视频附件仍是原文件直传（否则锁屏相册无法预览），需要附件也密文时应关闭「照片视频语音存云端」；② 加密开关是本机行为——你在网页版开启后，其它端（小程序/APK）在升级到同版本前会读到密文，换设备要在新设备的网页版输入同一密码。密码忘记无法找回，云端备份将永久无法解密。
2. **搭子数据是全量 JSON 落盘**：每次写都同步重写整个 `data.json`。房间数上限 `MAX_PAIRS=5000` 就是为此设的保护；要支撑更大规模应换成 SQLite 或追加日志。
3. **没有原生小组件/锁屏打卡，只有中文**：这是 PWA 的边界，需要 Capacitor/Tauri 之类的原生壳才能补。
4. **通知送达取决于系统**：iOS 需先"添加到主屏"；国产 ROM 常清理后台，后台轮询型提醒可能延后。系统日历（.ics 导出）是更可靠的路子。
5. **不做定位打卡**：这是习惯打卡应用，没有 `geolocation` 考勤校验；定位只用于天气兜底。
